# Password Strength Checker

A Python command-line program that checks a sample password's strength and gives suggestions.

## Checks

- Length
- Uppercase and lowercase letters
- Numbers
- Special characters

## Run

```bash
python password_strength_checker.py
```

The program hides the typed sample password and does not save it.

## Example results

- `StrongDemo123!` -> Strong
- `GoodPass1!` -> Medium
- `abc` -> Weak
